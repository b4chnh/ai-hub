# AI Hub for macOS

This repository hosts the public installers for AI Hub. The application source code is maintained privately and is not included here.

Download the latest installer from the [v1.0.8 release](https://github.com/b4chnh/ai-hub/releases/tag/v1.0.8). AI Hub requires macOS 14 or later on Apple Silicon.

GitHub automatically displays Source code ZIP/TAR links for every release. Those archives contain only this release repository's metadata, not the application source code. Use the attached DMG to install AI Hub.
